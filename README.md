# Albee Documentation

Tutorial documentation repository for the Albee desktop robot (ESP32-S3), available in English and Chinese.

## Languages

| Version | Entry |
|---|---|
| English | [Albee Encyclopaedia](./英文版本/albee-encyclopaedia.md) · [Project README](./英文版本/README.md) |
| 🇨🇳 中文版本 | [Albee 百科全书](./中文版本/Albee百科全书.md) · [Project README](./中文版本/README.md) |

📘 Product manual: [Albee Robot Manual.pdf](./docs/Albee%20Robot%20Manual.pdf)

## Structure

```
├── 中文版本/          # Chinese documents (translation)
│   ├── README.md
│   ├── Albee百科全书.md   # Encyclopaedia (index)
│   └── docs/          # Topic documents (Chinese file names)
├── 英文版本/          # English documents (original)
│   ├── README.md
│   ├── albee-encyclopaedia.md   # Encyclopaedia (index)
│   └── docs/          # Topic documents
├── docs/              # Product manual
│   └── Albee Robot Manual.pdf
└── assets/            # Images and downloadable assets shared by both versions
    ├── img/           # Images (one folder per document)
    └── account-help/  # Serial tools, unbind template, etc.
```
