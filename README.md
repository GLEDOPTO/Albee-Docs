# Albee 百科全书文档 / Albee Documentation

Albee 桌面机器人（ESP32-S3）教程文档仓库，中英双语，图片资源公用。

This repository holds the bilingual documentation for the Albee desktop robot (ESP32-S3). Images and downloadable assets are shared between both language versions.

## 语言 / Languages

| 版本 | 入口 |
|---|---|
| 🇨🇳 中文版本 | [Albee 百科全书](./中文版本/albee-encyclopaedia.md) · [项目 README](./中文版本/README.md) |
| 🇬🇧 英文版本 (English) | [Albee Encyclopaedia](./英文版本/albee-encyclopaedia.md) · [Project README](./英文版本/README.md) |

## 目录结构 / Structure

```
├── 中文版本/          # 中文文档（翻译版）
│   ├── README.md
│   ├── albee-encyclopaedia.md   # 百科全书（汇总索引）
│   └── docs/          # 各专题文档
├── 英文版本/          # English documents (original)
│   ├── README.md
│   ├── albee-encyclopaedia.md   # Encyclopaedia (index)

    ├── img/           # 图片（按文档名分目录）
    └── account-help/  # 串口工具、解绑模板等
```
