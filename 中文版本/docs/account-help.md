# 账号与设备问题

本页面介绍常见的账号问题：收不到短信验证码、忘记密码或用户名、解绑设备。

## 收不到短信验证码

正常情况下验证码 5 分钟内送达；国际手机号请最多等待 10 分钟。如果仍未收到，请检查手机是否停机、欠费，或短信是否被第三方安全软件拦截。

## 知道用户名但忘记了密码

- 如果账号绑定了手机号，可直接用短信验证码登录。
- 如果没有绑定手机号，请将**用户名**和**设备 ID** 发送邮件到 <xiaozhi.ai@tenclass.com>。

邮件主题格式：`【找回密码，用户名 XXX，设备 ID XXX】`

## 用户名和密码都忘了

- 如果账号绑定了手机号，可直接用短信验证码登录。
- 如果没有绑定手机号，请将**设备 ID** 和**激活日期**发送邮件到 <xiaozhi.ai@tenclass.com>。

邮件主题格式：`【找回用户名，设备 ID XXX，激活日期 XXX】`

## 如何获取设备 ID 和 MAC 地址

- **设备 ID** —— 设备能正常使用时，直接和它对话，让它告诉你。
- **MAC 地址** —— 需要下载串口工具，从串口日志中读取（见下方附录）。

## 设备已被其他账号绑定 —— 如何解绑

这种情况通常发生在开发板或芯片模块之前绑定过他人账号，退回或转卖前未在 xiaozhi.me 网站上解绑。

解绑请发送邮件到 <xiaozhi.ai@tenclass.com>，主题为：

`【解绑设备，设备 ID XXX，MAC 地址 XXX】`

如需解绑多台设备，请下载下方模板，填好设备 ID 和 MAC 地址，将填写完成的表格作为附件发送邮件，主题为 `【解绑设备】`：

[下载解绑模板（xlsx）](../../assets/account-help/xiaozhi-device-unbind-template.xlsx)

## 附录：如何查看 MAC 地址

1. 下载串口工具：[安信可串口工具 V2.0.1](../../assets/account-help/aithinker-serial-tool-v2.0.1.exe)

2. 将开发板/成品设备连接到电脑（如有电源开关，请确认已开机）。使用默认参数打开串口工具（无需调整），选择开发板的 COM 口，点击**打开串口**。如无报错，点击**运行模式**重启开发板，加载串口日志。

3. 在串口日志中，找到约 **(550) ms** 行附近的 `wifi:mode : sta ( ... )` —— 该行显示的值（下方截图中蓝色高亮部分）即为 MAC 地址。

![在串口工具日志中找到 MAC 地址](../../assets/img/account-help/serial-tool-mac-address.png)
