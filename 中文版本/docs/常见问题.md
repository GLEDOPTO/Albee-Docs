# Albee 桌面机器人常见问题

## 问题 1：如何调节 Albee 的音量？

**答：** Albee 支持语音调节音量。直接告诉 Albee 把音量设置到多少（1–100%），或直接说"把音量调大/调小一点"。也可通过 MCP 工具 `set_volume` 设置音量，参见[MCP 控制使用指南 · 工具目录](./MCP控制使用指南.md#工具目录)。

## 问题 2：如何重新配置或切换 Wi-Fi？

**答：** 重启 Albee。在 Wi-Fi 连接阶段蓝色 LED 闪烁时，短按一次**功能键**后松开 —— 会听到提示音，Albee 将重新进入 Wi-Fi 配网模式。

Albee 连续 3 次连接不上次配置的 Wi-Fi 后，也会自动重新进入 Wi-Fi 配网模式。更多切换/加入网络的方法（网页切换已保存网络、扫描加入新网络），参见[更换网络指南](./更换网络指南.md)。

> [!NOTE]
> 目前 Albee 只记住上一次连接的 Wi-Fi 和密码。如果切换到其他 Wi-Fi，或 Wi-Fi/热点被关闭，需要重新配网。

## 问题 3：Albee 支持播放音乐吗？

**答：** 支持 —— 支持测试音乐。由于版权限制，可用曲目仅限测试歌曲、用户投稿歌曲和部分儿歌。

## 问题 4：Albee 支持蓝牙吗？

**答：** 暂不支持。

ESP32-S3 芯片/模组支持 BLE 外设模式（只能被连接，不能主动发起连接），但 Albee 项目没有使用。如有需要，可自行编写代码实现。

## 问题 5：可以更换唤醒词吗？

**答：** 暂不支持修改唤醒词。

## 问题 6：可以更换音色吗？

**答：** 可以。进入 Albee 网页控制台 —— **角色配置** —— 切换角色音色。可以先试听，再提交保存配置。详细步骤参见[小智控制台配置指南 · 设置音色](./小智控制台配置指南.md#2-设置音色)。

控制台地址：<https://xiaozhi.me/>

## 问题 7：Albee 能通过声音认出并记住我是谁吗？

**答：** 可以。

**方法：** 进入 Albee 网页控制台 → **智能体（Agent）** → 找到**声纹识别**。详细步骤参见[小智控制台配置指南 · 声纹识别](./小智控制台配置指南.md#6-声纹识别)。

## 问题 8：可以用我自己的声音定制音色吗？

**答：** 支持 —— 目前处于公测阶段。

## 问题 9：Albee 能语音控制其他设备吗？

**答：** Albee 已支持 MCP 协议。详情参见[MCP 控制使用指南](./MCP控制使用指南.md)（含完整工具目录）；接入 Home Assistant 参见[Home Assistant 集成指南](./Home-Assistant集成指南.md)。

## 问题 10：Albee 支持 GPT 或其他大语言模型吗？

**答：** 暂不支持。如需使用其他大模型 API 或自部署模型，需要自行实现服务器。如需解锁更多模型（Qwen3 / DeepSeek 完整版 / 豆包 / GLM 等），参见[开发者认证](./开发者认证.md)；协议细节可参考[WebSocket 通信协议](./WebSocket通信协议.md)与[MQTT+UDP 混合通信协议](./MQTT-UDP混合通信协议.md)。

开源仓库：<https://github.com/78/xiaozhi>
