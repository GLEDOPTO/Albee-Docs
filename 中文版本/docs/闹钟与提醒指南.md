# 闹钟与提醒指南
> 适用固件：Albee v2.0.4 及以上 ｜ 适用对象：普通用户


本文档介绍机器人闹钟/提醒功能的语音用法和触发行为。该功能基于 MCP 协议实现（`add_reminder` / `delete_reminder` / `list_reminders` 三个工具；协议参见 [MCP控制使用指南.md](./MCP控制使用指南.md)）。代码位于 `main/boards/gledopto-robot/alarm/`。

## 1. 概述

机器人支持三种提醒模式，全部通过**语音**设置和管理：

| 模式 | 说明 | 示例 |
| ------------ | ---------------------------- | --------------------------- |
| **一次性** | 倒计时或指定时刻，触发后即失效 | "10 分钟后提醒我喝水" |
| **间隔重复** | 按固定间隔重复 | "每隔一小时提醒我喝水" |
| **每周重复** | 按星期几触发（"每天"即全选） | "每周一早上 9 点提醒我开会" |

- 所有提醒**存储在设备存储（NVS）中**，掉电、重启不丢失；
- 同时最多 **5** 个提醒 —— 添加新提醒前请先删除旧的；
- 提醒文字请**尽量简短（2–4 个词）** —— 屏幕显示区域有限。

## 2. 设置提醒

唤醒机器人（"Hi Albee"）后直接说：

### 倒计时提醒（一次性）

> "10 分钟后提醒我喝水"
> "30 秒后提醒我关火"

秒、分钟、小时均可作为时间单位。

### 定时提醒（每天）

> "每天早上 8 点提醒我吃药"
> "每天晚上 10 点提醒我睡觉"

每天同一时刻触发，触发后自动排定下一次。

### 每周提醒

> "每周一早上 9 点提醒我开会"
> "每周一三五晚上 7 点提醒我锻炼"

支持多种星期表述：

| 表述 | 含义 |
| ------ | -------------------------- |
| 每天 | 周一至周日 |
| 工作日 | 周一至周五 |
| 周末 | 周六、周日 |
| 组合 | 如"一三五"、"周一和周六" |

不说明上午/晚上时，时间默认为 8:00 —— 最好把时间说完整。

### 间隔重复提醒

> "每隔一小时提醒我喝水"

按固定间隔重复；可以加一句"一直提醒我"让它无限重复。

## 3. 查看提醒

> "查看我的闹钟" / "我有什么提醒"

机器人列出所有提醒，每条包含：**ID、触发时间、提醒文字、重复类型**（一次性 / 间隔 / 每周）。每周提醒会直接显示星期几，不用自己换算。

## 4. 删除提醒

> "删除我的闹钟"

清空**全部**提醒。

> "删除喝水的提醒"

删除文字匹配关键词（如"喝水"）的所有提醒。

## 5. 提醒触发时会发生什么

时间一到，机器人会：

1. 屏幕显示**时钟表情（时钟 GIF）**，下方显示"提醒：\<文字\>"；
2. 每 **3 秒**播放一次**"哔哔"提示音**，每轮 **10 次**（约 30 秒）；
3. 一轮无人响应 → **暂停 5 分钟**，期间屏幕回到中性表情并清除文字（一次性提醒的触发时间顺延 5 分钟，相当于贪睡）；
4. 5 分钟暂停后继续响铃，**最多 3 轮**；
5. 3 轮后自动结束：**一次性提醒自动删除**；重复提醒保留，等待下次触发。

## 6. 停止响铃

响铃期间，以下任意操作可立即停止：

| 操作 | 效果 |
| ------------------------ | -------- |
| **功能键单击** | 停止响铃 |
| **触摸控制单击 / 双击** | 停止响铃 |
| **直接和它说话**（语音唤醒） | 停止响铃 |

停止后，一次性提醒自动删除；间隔/每周提醒保留并继续按计划触发。

## 7. 提醒生命周期

| 阶段 | 行为 |
| ---------------------- | --------------------------------------- |
| 触发 | 时钟表情 + "提醒：\<文字\>"，播放提示音 |
| 响铃（10 × 3 秒） | 可通过按键 / 触摸 / 语音停止 |
| 暂停（5 分钟） | 中性表情；一次性提醒顺延 5 分钟 |
| 第 2 / 3 轮 | 时钟表情恢复，继续响铃 |
| 3 轮耗尽 | 自动结束；一次性提醒从存储中删除 |
| 中途手动停止 | 立即结束；一次性提醒从存储中删除 |

## 8. 限制与持久化

| 项目 | 说明 |
| ------------ | ------------------------------------------------------------ |
| 提醒数量上限 | 5 |
| 提醒文字 | 尽量简短（2–4 个词）；过长会被拒绝 |
| 响铃模式 | 每轮 10 × 3 秒，轮间暂停 5 分钟，最多 3 轮（总计约 10 分钟） |
| 存储 | 持久化到 NVS；掉电 / 重启不丢失 |

## 9. 常见问题

**问：闹钟响了怎么关？**
答：单击功能键、轻触触摸控制，或直接和它说话 —— 任意一种都行。一次性闹钟停止后会自动删除。

**问：暂停期间查看闹钟会显示过期时间吗？**
答：不会。暂停期间一次性提醒的时间已顺延 5 分钟，看到的总是未来的时间。

**问：闹钟会一直响吗？**
答：不会。最多 3 轮（约 10 分钟）后自动停止。

**问：重启后提醒还在吗？**
答：在。所有提醒存储在设备存储中，重启不丢失。

**问：一次最多能设几个提醒？**
答：最多 5 个；需要更多请先删除旧的。

**问：重复提醒响完会被删除吗？**
答：不会。间隔/每周提醒会自动排定下一次；只有一次性提醒在结束后删除。

**问："每天 8 点"和"每周一到周日 8 点"一样吗？**
答：等价。"每天"就是全选所有星期。
