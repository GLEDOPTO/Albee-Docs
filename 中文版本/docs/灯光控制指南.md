# 灯光控制指南

本文档介绍通过**网页**、**语音（AI）** 和 **HTTP API** 三种方式控制机器人所连接的灯光。相关代码位于 `main/boards/gledopto-robot/light/`（灯光控制核心）和 `main/boards/gledopto-robot/web/`（内置 Web 服务器）。

> **兼容性说明**：灯光控制功能**完全兼容所有格乐（GLEDOPTO）2.4G RF 灯带控制器**以及 **WLED 系列控制器** —— 无需适配，配对/添加后即可完整控制。

## 1. 概述

机器人作为灯光网关，支持两类灯光，统一以"分组"方式管理：

| 灯光类型 | 兼容性 | 通信方式 | 分组数 | 每组能力 | 掉电保存 |
| ---------- | ------------------------------------ | ---------------------------- | ------- | ----------------------------- | ---------------------- |
| **RF 灯** | **所有格乐 2.4G RF 灯带控制器** | 通过机器人内置 2.4G 模块直接 RF 控制 | 1–4 组 | 开关、亮度、颜色、色温 | 分组名、开关状态 |
| **WLED 灯带** | **WLED 系列控制器**（运行 WLED 固件） | 局域网内 HTTP 控制 | 1–4 组 | 开关、亮度、颜色、色温、效果 | 设备列表、分组名 |

路由规则（网页、语音、API 通用）：

- 按分组名或 `all`（全部）寻址：`all` 对两类灯的所有分组生效；**同名**的 RF 分组和 WLED 分组会被一起控制；
- 分组名支持模糊匹配（相似度 ≥ 80%），说得不太准确也能命中正确的分组；
- 分组名限制：非空、≤ 19 字节（约 6 个汉字）、不得与其他分组重名。

## 2. 打开控制页面

机器人接入 Wi-Fi 约 2 秒后，内置 Web 服务器自动启动（80 端口）。在浏览器打开：

```
http://<机器人IP>/light
```

获取机器人 IP 的方式：

- **串口日志**：在监视器（`idf.py monitor`）中过滤 `WebServer` —— 启动时会打印 `Access URL: http://x.x.x.x/light`；
- **路由器管理页**：查看新接入的设备；
- **语音询问**：问机器人"你的 IP 是多少"直接得到 IP；说"配置灯光"会播报完整的控制页地址（`IP/light`）。

页面分为两部分：上方 **RF 设备**（橙色边框），下方 **WLED 设备**（绿色边框）。

## 3. RF 灯控制

> 兼容**所有格乐 2.4G RF 灯带控制器**：任意型号上电后，按 3.1 的方法配对即可纳入控制。

<img src="../../assets/img/lighting-control/1.png" width="320" height="600">

### 3.1 首次配对（Pair）

RF 灯通过配对码绑定到机器人的某个分组：

1. 在网页上找到目标分组，点击**配对（Pair）**；
2. 确认对话框后，**在 5 秒内给 RF 灯/控制器断电重新上电**（重新上电的灯进入配对模式，记住该分组的配对码）；
3. 成功后页面显示 `Group N paired!`。

要点：

- 一次配对一个分组；要把多盏灯放进同一分组，在 5 秒窗口内一起断电重上电即可；
- 配对失败通常是断电重上电超过 5 秒导致的 —— 重试即可；
- 把灯移到别的分组：先在新分组 Pair 并先重启灯，之后可再 Clear 旧分组的配对码。

### 3.2 日常开关

- **分组开关**：每个分组卡片右侧的拨动开关；
- **总开关**：区块标题右侧的圆形电源按钮，依次向页面显示的所有分组发送开/关。

开关状态会持久化到 NVS，机器人重启后网页仍显示正确状态。

### 3.3 分组名

点击分组名输入框打开编辑对话框：

- 1–19 字节（约 6 个汉字）；不得与其他分组重名（前后端双重校验）；
- 重命名保存在机器人的 NVS 中，重启不丢失；
- 分组名是语音控制的寻址依据 —— 建议起一个容易说出口的名字，比如"客厅灯"。

### 3.4 显示分组数（+/-）

最后一个分组卡片下方的 **+ / -** 按钮可增减页面显示的分组数（1–4）。这只是**浏览器本地的显示设置**（存于 localStorage），不影响机器人内部已配对的分组。

### 3.5 清除配对（Clear / Clear All）

- **Clear**：清除单个分组的配对码；该分组的灯不再响应机器人；
- **Clear All**（分组 0）：清除所有分组的配对码。

清除后需重新 Pair 才能恢复控制。

## 4. WLED 灯带控制

> 兼容 **WLED 系列控制器**：与机器人同网段的任何运行 WLED 固件的设备都能被发现并完整控制。

### 4.1 添加设备

WLED 设备必须与机器人处于**同一局域网**。两种添加方式：

- **扫描设备（推荐）**：机器人通过 mDNS（`_wled._tcp`）扫描局域网，列出发现的设备；勾选并为每台选择分组，点击**添加所选**。已添加过的设备不会重复出现。
- **添加设备（手动）**：直接输入 WLED 的 IP 地址并选择分组。如果该 IP 已存在，会自动更新其分组。

设备数量上限为 **8** 台；标题栏显示当前数量 `(n/8)`。

### 4.2 管理设备

- 每台设备显示其 IP；点击**编辑**可修改分组或删除设备；
- 删除分组（WLED 区块的 **-** 按钮）：如果分组内有设备会弹出确认框，确认后该分组内的设备也会被删除；
- 分组名可点击重命名（默认：客厅 / 卧室 / 厨房 / 书房）；重命名保存在机器人的 NVS 中，组内设备自动迁移到新名字的分组。

### 4.3 开关与高级控制

- 网页提供分组开关和总开关（与 RF 相同）；
- **颜色、亮度、色温、效果**通过语音控制（见下一节）。

## 5. 语音（AI）控制

语音指令由 AI 后端转换为 MCP 工具调用（协议参见 [MCP控制使用指南.md](./MCP控制使用指南.md)）。主要工具：

| MCP 工具 | 功能 | 关键参数 |
| ------------------------------------------------------------ | ------------------------------------------ | ------------------------------------------------------- |
| `self.light.control_group` | 开/关/切换 | `group_name`（分组名或 `all`）、`action`（on/off/toggle） |
| `self.light.set_group_color` | 设置 RGB 颜色 | `group_name`、`r`/`g`/`b`（0-255） |
| `self.light.set_group_brightness` | 设置亮度 | `group_name`、`brightness`（0-255） |
| `self.light.set_group_color_temp` | 设置色温 | `group_name`、`temperature` |
| `self.light.set_group_effect` | WLED 效果 | `group_name`、`fx`（效果编号） |
| `self.light.get_all_group_name` | 列出所有分组名 | 无 |
| `self.light.get_ip` / `get_light_control_ip` | 获取设备 IP / 灯光控制页地址（`IP/light`） | 无 |
| `self.light.rf_pair_group` / `rf_clear_group` / `rf_clear_all` | RF 配对/清除 | `group_id` |

示例语句：

- "打开客厅灯" → `control_group("客厅灯", "on")`
- "把灯全部关掉" → `control_group("all", "off")`
- "把卧室灯带调成蓝色" → `set_group_color("卧室", 0, 0, 255)`
- "换个灯带效果" → `set_group_effect` / 随机效果

> 白光/暖光请优先使用色温工具而不是 RGB（RGB 白光偏红）。

## 6. HTTP API 参考

所有接口由机器人 80 端口提供，返回 JSON（含布尔字段 `success`）。可用于家庭自动化对接。

### RF 灯

| 接口 | 方法 | 请求体 | 说明 |
| -------------------- | ---- | -------------------- | -------------------------------------------------- |
| `/api/light/status` | GET | — | 返回所有 RF 分组 `[{id, name, state}]` |
| `/api/light/control` | POST | `{group_id, action}` | `group_id` 1-4；**0 表示全部分组**；`action`：on/off |
| `/api/light/rename` | POST | `{group_id, name}` | 分组名 ≤ 19 字节且唯一 |
| `/api/light/pair` | POST | `{group_id}` | 开启 5 秒配对窗口 |
| `/api/light/clear` | POST | `{group_id}` | 清除配对；0 表示全部 |

### WLED

| 接口 | 方法 | 请求体 | 说明 |
| ------------------------- | ---- | ------------------- | --------------------- |
| `/api/wled/devices` | GET | — | 设备列表 + 4 个分组名 |
| `/api/wled/scan` | GET | — | mDNS 扫描局域网 WLED 设备 |
| `/api/wled/add` | POST | `{name, ip, group}` | 添加设备（上限 8 台） |
| `/api/wled/edit` | POST | `{ip, name, group}` | 修改设备分组 |
| `/api/wled/delete` | POST | `{ip}` | 删除设备 |
| `/api/wled/control` | POST | `{ip, action}` | 单台设备开关 |
| `/api/wled/group/control` | POST | `{group, action}` | 按分组名开关 |
| `/api/wled/rename` | POST | `{group_id, name}` | 分组重命名（1-4） |

示例：

```bash
# 查看所有灯组状态
curl http://192.168.1.50/api/light/status

# 打开 RF 分组 2（分组号从 1 开始）
curl -X POST http://192.168.1.50/api/light/control \
     -H "Content-Type: application/json" \
     -d '{"group_id": 2, "action": "on"}'

# 关闭名为"卧室"的 WLED 分组
curl -X POST http://192.168.1.50/api/wled/group/control \
     -H "Content-Type: application/json" \
     -d '{"group": "卧室", "action": "off"}'
```

## 7. 常见问题

- **控制页打不开**：确认机器人已接入 Wi-Fi，且手机/电脑与它在同一网段；查看串口日志中 `Access URL` 打印的 IP；路由器 DHCP 可能改变 IP，建议在路由器上为机器人绑定静态 IP。
- **RF 配对总是失败**：点击配对后必须在 **5 秒内**完成断电重新上电；电池电量耗尽或供电不足的灯也可能收不到配对码。
- **扫描不到 WLED**：确认 WLED 设备与机器人同一局域网（注意开启了 AP 隔离的路由器）；也可以用"添加设备"手动输入 IP。
- **带分组名的语音指令没反应**：分组名以网页显示为准；用 `get_all_group_name` 或网页核对实际名称；说法太随意可能低于 80% 相似度阈值。
- **RF 和 WLED 同名分组"被误控"**：这是设计行为（同名分组联动）；如需独立控制请重命名。
