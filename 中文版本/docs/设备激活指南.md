# 设备激活指南
> 适用固件：Albee v2.0.4 及以上 ｜ 适用对象：普通用户


## 一、按键与操作

Albee 身上有**两个物理按键**和**一处触摸控制**：

| 名称 | 说明 | 操作 |
| --- | --- | --- |
| 电源按键（Power Button） | 机身电源键 | 长按 3 秒开机 / 关机 |
| 功能键（Function Button） | 即 BOOT 键 | 见下表 |
| 触摸控制 | 机身触摸区域 | 单击 / 双击（与功能键单击同样可停止闹铃） |

**功能键（Function Button）的操作：**

| 操作 | 作用 |
| --- | --- |
| 单击 | ① 停止正在响的闹铃；② 开始或结束一轮对话；③ 开机后若一直未能成功连接 Wi-Fi，单击即可重新进入配网模式（无需断电重启） |
| 双击 | 切换「实时打断」功能（开启后不必等播报结束，直接说话即可打断） |
| 长按 10 秒 | 恢复出厂设置：清除 Wi-Fi 凭据、闹钟、灯光分组等全部用户设置，并自动重启；重启后需重新配网 |

> [!WARNING]
> 长按功能键 10 秒会清空全部用户设置并立即重启，**操作时请避免误按**（例如把机器人放进行李箱、或按键被长时间压住时）。

## 二、开机和配网

1. **设备开机**：长按电源按键（Power Button）3 秒，直到指示灯和屏幕亮起。

<img src="../../assets/img/device-activation/1.png" width="560">

2. **连接设备热点**：开机后，Albee 屏幕会显示一个名称为 **Albee-xxxx** 的 Wi-Fi 热点。在手机的 Wi-Fi 设置中找到并连接该热点。

<img src="../../assets/img/device-activation/8.png" width="360">

3. **打开配网页面**：连接成功后，手机通常会自动打开配网页面。若页面未自动弹出，请打开手机浏览器，在地址栏输入 `192.168.4.1` 并访问。在配网页面中选择或输入要连接的 Wi-Fi 名称（SSID），并输入对应的密码。

<img src="../../assets/img/device-activation/9.png" width="480">

4. 点击**Connect**
5. 等待重启

### 3. 设置角色介绍

**角色介绍：** 用于设定 AI 机器人的角色身份、性格和交流方式，让机器人按照配置的角色与你交互。

例如可以设定**儿童陪伴、英语老师、智能管家、故事伙伴、趣味聊天**等角色，满足不同场景需求。

<img src="../../assets/img/xiaozhi-console/4.png" width="560">

**参考模板**

现成的 Albee 角色介绍模板（中英双版）请见 [小智控制台配置指南 · 设置角色介绍](./小智控制台配置指南.md#3-设置角色介绍)。

### 4. 切换模型

<img src="../../assets/img/xiaozhi-console/5.png" width="560">

默认选择小智 Lite；其他模型在完成开发者认证之前不可用。详情参见[开发者认证](./开发者认证.md)

### 5. 切换记忆模式

开启后，机器人不必在每次对话中"重新认识你"；关闭后，每次对话都"从零开始"。

<img src="../../assets/img/xiaozhi-console/6.png" width="560">

### 6. 声纹识别

**声纹识别：** 通过不同用户的语音特征识别"谁在说话"。录入声纹后，机器人可以识别特定用户，实现**个性化称呼、专属交互、区分家庭成员**，让交流更智能、更有温度。
