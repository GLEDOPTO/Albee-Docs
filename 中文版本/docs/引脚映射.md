# 引脚映射
> 适用固件：Albee v2.0.5 ｜ 适用对象：开发者


Albee 桌面机器人（ESP32-S3）的完整 GPIO 引脚映射，覆盖板上的所有外设、传感器和按键。

## GPIO 引脚表

| GPIO | 分组 | 功能 |
| --------- | ------------------- | ------------------------------------------------------ |
| IO7 | 电源管理 | 电池电压采样（12 位 ADC，3.0–4.2 V 校准曲线） |
| GPIO21 | 电源管理 | 充电检测（低电平 = 充电中） |
| GPIO45 | 电源管理 | GEK100 电源模块控制（低电平 = 正常供电） |
| GPIO0 | 按键输入 | 功能键（Function Button，即 BOOT 键）单击 / 双击 |
| GPIO4 | 按键输入 | 触摸控制（单击 / 双击） |
| GPIO1 | I2C 总线 | I2C SDA —— SC7U22 六轴 IMU 和 4 × LTR-553 足部传感器 |
| GPIO2 | I2C 总线 | I2C SCL —— 同一总线 |
| GPIO3 | LCD 显示 | LCD 背光 PWM |
| GPIO9 | LCD 显示 | SPI CLK（与 LT8900 共用） |
| GPIO10 | LCD 显示 | SPI MOSI（与 LT8900 共用） |
| GPIO11 | LCD 显示 | LCD 复位 |
| GPIO12 | LCD 显示 | LCD 片选（CS） |
| GPIO46 | LCD 显示 | LCD D/C（数据/命令） |
| GPIO8 | LT8900 射频 | LT8900 SPI MISO |
| GPIO13 | LT8900 射频 | LT8900 片选（CS） |
| GPIO41 | LT8900 射频 | LT8900 复位 |
| GPIO42 | LT8900 射频 | LT8900 PKT（数据就绪） |
| GPIO17 | 舵机 | 左腿舵机 |
| GPIO18 | 舵机 | 左脚舵机 |
| GPIO38 | 舵机 | 右脚舵机 |
| GPIO39 | 舵机 | 右腿舵机 |
| GPIO15 | 灯环 | WS2811 可寻址 RGB LED 数据 |
| GPIO47 | 语音芯片 | VB6824 编解码器 TX |
| GPIO48 | 语音芯片 | VB6824 编解码器 RX |

## 说明

- **I2C 总线（GPIO1/GPIO2）**：由 SC7U22 六轴 IMU（加速度计 + 陀螺仪，Mahony AHRS 姿态融合，输出欧拉角和四元数；检测站立 / 倾斜 / 跌倒 / 摇晃状态）和四个 LTR-553 红外接近传感器（每脚两个，用于防跌落 —— 悬空 / 着地检测）共用。
- **共用 SPI 线（GPIO9/GPIO10）**：SPI 时钟和 MOSI 由 ST7789 LCD 和 LT8900 射频模块共用；两个设备靠各自独立的片选线区分（GPIO12 与 GPIO13）。
- **LCD**：1.54 英寸 240×240 ST7789，用于显示 21 个 GIF 表情和 5 个状态动图（低电量 / 充电 / 时钟 / 开机 / Wi-Fi）。
- **Wi-Fi**：由 ESP32-S3 片上 2.4 GHz 射频提供（云端对话、WLED 控制、mDNS）—— 不占用外部引脚。
- **电源**：系统由 GEK100 电源模块供电；电池电压经 IO7 采样，使用 3.0–4.2 V 校准表，低电量自动关机。
