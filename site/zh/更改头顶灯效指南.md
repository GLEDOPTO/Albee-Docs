## 二、通过代码修改

> 适用对象：要改出厂行为、增加新效果或调整状态映射的开发者
>
> 前提是需要下载源码并且搭建号编译环境，可查看 [固件编译教程](固件编译教程.md)

### 2.1 效果链路总览

| 环节        | 位置                                               | 职责                              |
| ----------- | -------------------------------------------------- | --------------------------------- |
| 状态 → 槽位 | `led_config.cc` · `LedSlotFor()`                   | `DeviceState` 映射到 `LedSlot`    |
| 槽位默认值  | `led_config.cc` · `kLedDefaults[]`                 | 出厂效果 / 颜色 / 节奏            |
| 配置读写    | `led_config.cc` · `LedConfig`                      | NVS 持久化、范围校验、revision    |
| 效果名列表  | `led_config.cc` · `kEffectNames[]`                 | 经 API 下发，设置页下拉框据此生成 |
| 效果分发    | `circular_strip.cc` · `CircularStrip::ApplySlot()` | 按`effect` 字段调用动画           |
| 动画实现    | `circular_strip.cc`                                | 逐帧绘制（帧定时器回调）          |

前端（`pages/led.html`）完全按 API 返回渲染，**改效果、加效果、加槽位都不需要动前端**。

### 2.2 改某状态的默认外观

改 `led_config.cc` · `kLedDefaults[]`。数组行与 `LedSlot` 枚举顺序一一对应：

| 下标 | 0        | 1                | 2    | 3          | 4         | 5        | 6         | 7          |
| ---- | -------- | ---------------- | ---- | ---------- | --------- | -------- | --------- | ---------- |
| 槽位 | starting | wifi_configuring | idle | connecting | listening | speaking | upgrading | activating |

每行是 `LedStateConfig`：`{effect, mode, r, g, b, length, interval_ms}`。`r/g/b` 仅 `kCustom` 模式使用；`length` 仅 Scroll 使用。

例——Idle 由"渐灭"改为"蓝色呼吸 2 s"：

```cpp
// kLedDefaults 中 idle（下标 2）一行
{LedEffect::kBreathe, LedColorMode::kAutoBlue, 0, 0, 0, 3, 2000},
```

改后同步更新 `kLedDefaults[]` 上方的"逐值对照"注释。

**生效条件分两类（易踩坑）**：

- **非锁定槽**：NVS 里已有该槽键（`st{i}` / `si{i}`）的存量设备**继续用 NVS 值**，看不到新默认值。要生效需在网页「指示灯」卡片点 Reset（走 `/api/led/reset` → `LedConfig::ResetToDefaults()`），或擦除 `led` namespace。
- **锁定槽**（`starting` / `wifi_configuring` / `upgrading`）：`LedConfig::LoadLocked()` 每次开机把 effect / length / interval 强制回 `kLedDefaults`，改代码**立即生效**；颜色仍从 NVS 读。

### 2.3 改「状态 → 槽位」映射

`led_config.cc` · `LedSlotFor()`——加一个 case 即可让某状态复用现有灯效：

```cpp
case kDeviceStateFatalError: return kLedSlotListening;
```

（默认 Unknown / FatalError 返回 -1，无灯效。）若希望该状态有**独立**配置，按下节新增槽位。

### 2.4 新增一个槽位

要把两个状态拆成两套独立配置（例如 `AudioTesting` 从 `Listening` 独立），需同步改 6 处，集中在 `led_config.h` / `led_config.cc`：

1. `led_config.h` · `LedSlot` 枚举——**新槽加在 `kLedSlotCount` 之前（末尾）**，旧 NVS 键全部不受影响；
2. `led_config.cc` · `kSlotKeys[]`——NVS 与 JSON 的键名；
3. `led_config.cc` · `kSlotLabels[]`——设置页显示名；
4. `led_config.cc` · `kLedDefaults[]`——新增一行；
5. `led_config.cc` · `kLedSlotLocked[]`——新增一项；
6. `led_config.cc` · `LedSlotFor()`——加 case。

前端与 API 零改动：`web_led_api.cc` 按 `kLedSlotCount` 遍历输出，页面按返回数据渲染。

### 2.5 新增一种灯效

固件四步，前端零改动：

1. **枚举**：`led_config.h` · `LedEffect` 加项——必须加在 `kCount` 之前，且**不要插在中间**：NVS 存的是枚举数值，插中间会改变存量存档的含义；
2. **显示名**：`led_config.cc` · `kEffectNames[]` 加一项，索引与枚举值对齐，顺序即设置页下拉顺序；
3. **动画实现**：在 `circular_strip.cc` 中参照 `Breathe()` / `Scroll()` 写新动画，三条约定：
   - 用 `StartStripTaskLocked(interval_ms, cb)` 启动帧定时器（调用点已持 `mutex_`），或 `StartStripTask()`（自动加锁）；
   - 动画相位变量（呼吸亮度、滚动偏移等）**必须是 `CircularStrip` 成员**（参照 `circular_strip.h` 里 `blink_on_` 那一批声明），不能用函数内 `static`——旧实现正是如此，导致动画重启时从上次相位继续；
   - 帧回调运行在 `strip_timer` 的 esp_timer 任务上、持有 `mutex_`；`led_strip_refresh()` 同步阻塞 RMT 传输；
4. **分发**：`CircularStrip::ApplySlot()` 的 switch 加 case。

**位宽限制**：槽位配置打包存 NVS 时 effect 只占 3 bit（见 `led_config.cc` 的 `PackSlot()` / `UnpackSlot()`），现用 6 种（值 0–5），**最多还能加 2 种**（值 6、7）；再加需扩 `kShiftEffect` 之后的效果位宽，并同步两处掩码、`kSchemaVersion` 与兼容迁移。

### 2.6 微调现有动画的逐帧行为

均在 `circular_strip.cc`：

- 呼吸步长：`Breathe()` 内的 `* 3`（越大越快）；
- 彩虹转速：`Rainbow()` 内 `step = 360000 / 24 / interval_ms`（一圈约 24 帧）；
- 滚动前进量：`Scroll()` 末尾的偏移递增；
- 闪烁占空比：`Blink()` 的亮灭翻转。

另注意 `Breathe(low, high, …)` 的第一个参数目前未使用，实际只按 `high` 缩放。

### 2.7 校验范围常量

`led_config.h`：`kLedIntervalMinMs` / `kLedIntervalMaxMs`（节奏 50–5000 ms）、`kLedScrollLenMin` / `kLedScrollLenMax`（Scroll 亮段 1–7 颗）、`kLedBrightnessMin` / `kLedBrightnessMax`（亮度百分比 0–100）。API 校验（`LedConfig::ValidateSlotPatch()`）与 NVS 读回共用这些值，改一处即全链路生效。

### 2.8 编译与生效

- 只改现有文件 → `idf.py build flash`；
- **新增 `.cc` 文件** → 先 `idf.py reconfigure`（源码按 GLOB 收集，不会自动重扫）；
- 改了 NVS 打包格式 → bump `led_config.cc` 的 `kSchemaVersion` 并考虑旧值迁移；
- 存量设备要看新默认值 → 网页 Reset 或擦 `led` namespace

### 2.9 避坑清单

- `main/boards/gledopto-robot/light/`（`rf_light` / `wled_light`）是**外部 RF / WLED 灯具**驱动，与板载指示灯无关，别改错目录；
- `main/led/` 是板级公共代码：`led_config.h` 的约定是不得 include `board.h` / `application.h`（每块板都会编译它）；
- 想让锁定槽可编辑 → 改 `kLedSlotLocked[]`；解除后 `PreviewSlot()` 的预览限制自动放开；
- 运行中改配置无需手动重启动画：`LedConfig` 每次成功写入会递增 revision，`CircularStrip::OnStateChanged()` 下次调用时自动重绘。
