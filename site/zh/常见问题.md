# Albee 常见问题

> 适用固件：Albee v2.0.4 及以上 ｜ 适用对象：普通用户

## 一、按键与操作

**Q：Albee 有几个按键？分别做什么？**

A：两个物理按键 + 一处触摸控制。电源按键长按 3 秒开关机；功能键单击开始或结束一轮对话（闹铃响时单击停止响铃）、双击切换实时打断、长按 10 秒恢复出厂设置；触摸控制支持单击与双击，同样可以停止闹铃。详见[设备激活指南 · 按键与操作](设备激活指南.md#一按键与操作)。

**Q：怎么恢复出厂设置？**

A：长按功能键 10 秒。设备会清除 Wi-Fi 凭据、闹钟、灯光分组等全部用户设置并自动重启，重启后需重新配网。**请避免误按**（按键被长时间压住会触发）。

## 二、配网与联网

**Q：如何重新配置或切换 Wi-Fi？**

A：重启 Albee，在 Wi-Fi 连接阶段蓝色 LED 闪烁时短按一次功能键，听到提示音后即重新进入配网模式；连续 3 次连不上已保存的 Wi-Fi 也会自动重新配网。网页切换与扫描加入新网络见[更换网络指南](更换网络指南.md)。

**Q：开机后一直连不上 Wi-Fi 怎么办？**

A：无需断电重启 —— 直接**单击功能键**即可重新进入配网模式；设备连续 3 次连接失败也会自动重新配网。其它方式（网页切换已保存网络、扫描加入新网络）见[更换网络指南](更换网络指南.md)。

**Q：怎么知道设备的 IP 地址？**

A：见[获取设备 IP 地址](获取设备IP地址.md) —— 对话询问、路由器后台、串口日志三种方式任选。

## 三、语音与对话

**Q：音量怎么调？**

A：直接说"把音量调到 50"或"音量调大一点"（1–100%）；也可通过 MCP 工具 `set_volume`，参见[MCP 控制使用指南 · 工具目录](MCP控制使用指南.md#工具目录)。

**Q：能播放音乐吗？**

A：支持，但受版权限制，可用曲目仅限测试歌曲、用户投稿歌曲和部分儿歌。

**Q：支持蓝牙吗？**

A：暂不支持。

**Q：可以更换唤醒词吗？**

A：暂不支持，默认唤醒词为 "Hi Albee"。

**Q：可以更换音色吗？**

A：可以。控制台 → 角色配置 → 切换音色，可先试听再保存，参见[小智控制台配置指南 · 设置音色](小智控制台配置指南.md#2-设置音色)。

**Q：能认出并记住我是谁吗？**

A：可以。控制台 → 智能体 → 声纹识别，参见[小智控制台配置指南 · 声纹识别](小智控制台配置指南.md#6-声纹识别)。

**Q：可以用我自己的声音定制音色吗？**

A：支持，目前处于公测阶段。

**Q：支持 GPT 等其他大模型吗？**

A：默认不支持。完成[开发者认证](开发者认证.md)后可解锁 Qwen3 / DeepSeek 完整版 / 豆包 / GLM 等更多模型。

B：可自行搭建服务器接入其它大模型，参考[相关开源项目](README.md#related-projects)。

**Q：可以自己搭建服务器吗？**

A：可以。小智的通信协议是开放的，社区提供了 Python / Java / Golang 等多种服务端实现，可自行部署到个人电脑或云服务器，接入自己选择的大模型。搭建前可参考[相关开源项目](README.md#related-projects)与[通信协议文档](WebSocket通信协议.md)。

## 四、灯光与动作

**Q：能语音控制家里的灯吗？**

A：可以，支持 RF 灯 4 组与 WLED 灯 4 组，参见[灯光控制指南](灯光控制指南.md)；接入 Home Assistant 见[Home Assistant 集成指南](Home-Assistant集成指南.md)。

**Q：机器人走路姿态不对、腿脚角度有偏差？**

A：可能是舵机复位姿态有微小偏差，通过网页 `http://设备IP/robot` 对四个舵机做 ±1° 微调，参见[舵机校准指南](舵机校准指南.md)。

## 五、账号与激活

**Q：收不到短信验证码？**

A：正常 5 分钟内送达，国际手机号最多等 10 分钟；检查手机是否停机、欠费，或短信被安全软件拦截。

**Q：忘记密码或用户名？**

A：参见[账号与设备问题](账号与设备问题.md)。

**Q：设备已被其他账号绑定？**

A：邮件联系售后解绑，参见[账号与设备问题](账号与设备问题.md)。

## 六、升级与故障

**Q：怎么升级固件？**

A：优先用设备内置网页上传 `.ota` 文件，无需电脑烧录，参见[本地OTA升级指南](本地OTA升级指南.md)。

**Q：设备死机或无故重启怎么办？**

A：按[设备死机或重启问题反馈指南](设备死机或重启问题反馈指南.md)收集启动原因与日志，邮件反馈售后。
