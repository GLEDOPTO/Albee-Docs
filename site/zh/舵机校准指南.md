# 舵机校准指南
> 适用固件：Albee v2.0.5 ｜ 适用对象：普通用户


> 为什么需要校准？复位状态下机器人是站姿，四个舵机都是处于90°角度，可能因某些原因导致机器人复位姿态有微小的偏差，这个会导致机器人走路不正确

## 校准步骤

1. 确保设备已激活已联网
2. 获取设备 IP 地址（见[获取设备 IP 地址](获取设备IP地址.md)），然后用手机或电脑连接同一个 Wi-Fi（确保同一局域网）
3. 通过浏览器访问：http://<机器人IP>/robot
4. 静止状态下去调整对应的舵机，点击-1°/+1°可以微调四个舵机（**注意调整机器人时应该放倒，脸朝上**）
