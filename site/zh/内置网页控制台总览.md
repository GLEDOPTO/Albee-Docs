# 内置网页控制台总览

> 适用固件：Albee v2.0.4 及以上 ｜ 适用对象：普通用户

Albee 联网后会在局域网内提供一组网页，用手机或电脑浏览器即可直接管理设备，无需安装 App。本篇是这些页面的入口说明。

## 一、前置条件

1. Albee 已激活并联网
2. 手机或电脑与 Albee 连接同一个 Wi-Fi（同一局域网）
3. 已知设备的 IP 地址 —— 获取方式见[获取设备 IP 地址](获取设备IP地址.md)
4. 浏览器访问 `http://<设备IP>/<页面>`，例如 `http://192.168.1.50/light`

## 二、页面一览

| 访问地址 | 用途 | 详细说明 |
| --- | --- | --- |
| `http://<设备IP>/light` | 灯光控制：RF 灯配对与分组、WLED 设备扫描与分组、分组开关 | [灯光控制指南](灯光控制指南.md) |
| `http://<设备IP>/network` | 切换已保存的 Wi-Fi、扫描并加入新网络 | [更换网络指南](更换网络指南.md) |
| `http://<设备IP>/led` | 修改头顶灯环在各设备状态下的灯效 | [更改头顶灯效指南](更改头顶灯效指南.md) |
| `http://<设备IP>/robot` | 舵机校准：四个舵机 ±1° 微调 | [舵机校准指南](舵机校准指南.md) |
| `http://<设备IP>/info` | 设备信息：MAC 地址、固件版本、启动原因等 | [如何查看MAC地址](如何查看MAC地址.md) |
| `http://<设备IP>/update` | 本地 OTA：上传 `.ota` 文件升级固件 | [本地OTA升级指南](本地OTA升级指南.md) |

> [!NOTE]
> `/robot`（运动控制与舵机校准）需要固件编译时开启 `enable web robot control` 选项；出厂固件若未开启，该页面不可用，其余页面不受影响。

## 三、常见问题

- **页面打不开**：确认在同一局域网、IP 未变化；路由器开启 AP 隔离会阻断设备间访问。
- **页面提示需要激活**：未激活的设备只提供配网相关页面，请先完成[设备激活](设备激活指南.md)。
- **改了设置没生效**：网页上的灯效、网络等设置即时生效；而控制台侧（角色、音色、模型）的配置需要重启设备后才生效。
- **升级失败**：确认上传的是 `.ota` 文件而非 `.bin`，且过程中不要断电，详见[本地OTA升级指南](本地OTA升级指南.md)。
