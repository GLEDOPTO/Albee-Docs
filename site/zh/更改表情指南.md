# 更改表情指南
> 适用固件：Albee v2.0.5 ｜ 适用对象：普通用户


## 一、通过设备网页在线更换（推荐）

无需编译固件，在浏览器里即可上传、替换、删除表情：

1. 浏览器访问 `http://<设备IP>/emoji`（IP 获取见[获取设备 IP 地址](获取设备IP地址.md)）。
2. 页面列出已安装表情的缩略图（内置与自定义均有）：点击任意表情可在机器人屏幕上预览；点缩略图右上角 ⟳ 可为该表情另选替换文件（文件无需改名）；点 ✕ 删除自定义表情——**内置表情只能替换、不能删除**。
3. 上传新表情：选择一个或多个 `.gif` / `.png` 文件。文件名（不含扩展名）即表情名，规则：小写字母开头，仅含 `a-z`、`0-9`、`-`、`_`，最长 27 个字符；与已装表情同名即替换、新名字即新增。单文件 ≤ 1 MB，图片尺寸 ≤ 240×240。
4. 上传与删除先进入 "Pending（待应用）" 列表，不会立即生效；点 **Apply & reboot** 一次性应用全部改动（设备重建资源包并自动重启后生效），点 **Discard** 全部放弃。待应用列表断电/重启不丢失；应用过程中断电不会变砖，重启后自动恢复或回退。
5. 限额：表情资源包整体 ≤ 2 MB，待应用暂存区 ≤ 1 MB，页面实时显示用量与"应用后预计大小"，超限需先删除部分表情。
6. 若设备设置过网页 PIN 锁，上传/删除/应用/预览需先解锁；浏览列表与缩略图不需要。

> **提示：**
> - 资源包内置开机表情 `power-on`（联网前播放约 3 秒后回到 neutral），它同样是内置表情，可在本页替换。
> - 经小智后台下发资源包（第二节）、或重新编译固件并烧录（第三节），都会**整体覆盖**资源分区，网页上传的自定义表情会丢失。
> - 通过网页上传的自定义表情，还可以用语音点播：对机器人说"播个表情 xxx"，或详见 [MCP控制使用指南](MCP控制使用指南.md) 中的 `self.screen.show_emoji` 工具。

## 附：表情管理 HTTP 接口（进阶）

`/emoji` 页面背后的接口（`main/boards/gledopto-robot/web/web_emoji_api.cc`），供脚本或第三方集成使用。GET 请求无需解锁；写操作在设备设置过 PIN 时需先解锁。

| 端点 | 方法 | 请求 | 响应/行为 |
|---|---|---|---|
| `/api/emoji/list` | GET | — | `{"success":true,"emojis":[{"name","file","size","builtin"}]}`（size 单位字节；builtin=是否内置） |
| `/api/emoji/file?name=<文件名>` | GET | 文件名带 `.gif`/`.png` 后缀 | 图片字节流；带 ETag，命中 `If-None-Match` 回 304 |
| `/api/emoji/status` | GET | — | `{"state":"idle/working/done/error"[,"error"]}`（重建任务状态） |
| `/api/emoji/staged` | GET | — | `{"staged":[{"name","op":"add/remove","size"}],"space":{"package_used","package_max","stage_used","stage_max","est_after_apply"},"rev":<条目计数>}`（space 各值单位 KB） |
| `/api/emoji/staged?name=xx&op=add` | POST | body 为裸 GIF/PNG 字节 | 暂存新增/替换（校验：≤1 MB、≤240×240、名字规则） |
| `/api/emoji/staged?name=xx&op=remove` | POST | — | 暂存删除；内置表情与未安装的名字被拒 |
| `/api/emoji/staged` + `{"clear":true}` | POST | — | 清空整个待应用列表 |
| `/api/emoji/commit` | POST | — | 应用全部暂存改动：后台重建资源包，约 3 秒后自动重启 |
| `/api/emoji/play` | POST | `{"name":"happy"}` | 屏幕即时预览指定表情 |

错误统一为 `{"success":false,"error":"<原因>"}`。
