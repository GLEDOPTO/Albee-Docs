# 固件烧录指南

> 适用固件：Albee v2.0.4 及以上 ｜ 适用对象：开发者

两种方式：用电脑上的 Flash Download Tool 烧录（无需搭建 IDF 环境），或通过网页浏览器烧录。日常升级更推荐[本地 OTA](本地OTA升级指南.md)（网页上传 `.ota` 文件，无需电脑）。

## 1. 用 Flash Download Tool 烧录

### 1.1 准备

1. 安装 Flash Download Tool：<https://dl.espressif.com/public/flash_download_tool.zip>
2. 准备固件文件
3. 用 Type-C 数据线把机器人接到电脑，确认设备已开机（长按电源按键 3 秒）

> [!IMPORTANT]
> 建议使用设备原装数据线，或确认所用数据线支持数据传输

### 1.2 下载设置

1. 芯片类型选择 **ESP32-S3**
2. 工作模式选择 **Develop**
3. 加载模式推荐 **UART**

<img src="../assets/img/flashing-interface.png" width="560">

### 1.3 烧录步骤

1. 点击第一行空白处的选择按钮，导入 `.bin` 固件文件
2. 勾选该文件行前的复选框（必须勾选），并在后面的输入框中填入烧录地址 `0x0`
3. 选择对应的 COM 口
4. 点击 **START** 开始烧录，进度条完成后状态显示 **FINISH**
5. 烧录完成后重启设备（长按电源按键 3 秒关机，松开后再次长按 3 秒开机）

## 2. 通过网页浏览器烧录

1. 设备开机
2. 用 Type-C 数据线把机器人接到电脑
3. 在浏览器中打开烧录页面并下载固件

## 3. 错误信息与故障排除

**问题 1：不显示 COM 口？**

1. 检查设备是否开机
2. 检查所用的数据线是否支持数据传输
3. 重启设备，并尝试多次插拔

**问题 2：烧录后程序不能正常运行？**

1. 检查设备是否开机
2. 确认烧录地址填写为 `0x0`
