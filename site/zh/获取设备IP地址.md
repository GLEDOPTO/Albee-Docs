# 获取设备 IP 地址

> 适用固件：Albee v2.0.4 及以上 ｜ 适用对象：普通用户

打开 Albee 的内置网页（灯光控制、网络切换、灯效、舵机校准、本地升级等）都需要先知道它的 IP 地址。下面三种方法任选其一。

## 方法一：直接问它（最省事）

唤醒 Albee（说 "Hi Albee" 或单击功能键）后，说以下任意一句，它会语音播报并在屏幕上显示 IP 地址：

- "你的 IP 地址是多少？"
- "播报 IP 地址"
- "告诉我你的地址"

## 方法二：路由器后台查看

1. 登录路由器管理页面（常见地址 `192.168.1.1` 或 `192.168.0.1`，以路由器底部标签为准）
2. 找到「已连接设备」或「DHCP 客户端列表」
3. 列表中名称含 **Albee** 的条目即为机器人，旁边显示的即是 IP 地址

> [!TIP]
> 建议在路由器后台把该 IP 与设备 MAC 绑定为静态分配，避免重启后 IP 变化导致网页打不开。

## 方法三：通过串口日志查看

1. 用 Type-C 数据线把 Albee 接到电脑（设备需处于开机状态）
2. 打开串口调试软件（Tera Term、CoolTerm 等），选择对应的 COM 口，波特率 **115200**，其它保持默认
3. 设备连上 Wi-Fi 后，日志中会出现下面两行，其中的 `192.168.0.171` 就是设备在当前局域网中的 IP 地址：

```
I (11563) esp_netif_handlers: sta ip: 192.168.0.171, mask: 255.255.255.0, gw: 192.168.0.1
I (11563) WifiStation: Got IP: 192.168.0.171
```

> [!NOTE]
> 两行中的地址相同，认 `sta ip:` 或 `Got IP:` 任意一个即可。若日志里只有 `wifi:connected with xxxx` 而没有 `Got IP`，说明 Wi-Fi 已连上但还没拿到 IP，请稍等或检查路由器 DHCP。

## 常见问题

- **网页打不开？** 确认手机 / 电脑与 Albee 在同一局域网（同一 Wi-Fi），且路由器未开启 AP 隔离。
- **昨天能打开、今天打不开？** 多为路由器重新分配了 IP，按上述方法重新获取即可；建议绑定静态 IP。
- **问它不回答？** 设备需已激活并成功联网；配网中或连接服务器中的状态下还拿不到 IP，请改用方法二或方法三。
