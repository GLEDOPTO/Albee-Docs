# 更换网络指南
> 适用固件：Albee v2.0.4 及以上 ｜ 适用对象：普通用户


## 一、通过按键切换

1. 重启设备

2. 当头顶 LED 效果是蓝色滚动流水灯（或者重启后 3 秒内）单击一次功能键（Function Button）

> [!TIP]
> 如果开机后一直未能连上 Wi-Fi，不必断电重启 —— 直接单击一次功能键即可重新进入配网模式。

   <img src="../assets/img/change-wifi/2.png" width="480">

## 二、通过网页切换已保存的网络

1. 确保设备已激活已联网
2. 获取设备 IP 地址（见[获取设备 IP 地址](获取设备IP地址.md)），然后用手机或电脑连接同一个 Wi-Fi（确保同一局域网）
3. 通过浏览器访问：http://<机器人IP>/network
4. 找到 SWITCH NETWORK 区块，点击非当前连接网络的 Switch 按钮

<img src="../assets/img/change-wifi/1.png" width="480">



## 三、加入新网络（扫描）

1. 确保设备已激活已联网
2. 获取设备 IP 地址（见[获取设备 IP 地址](获取设备IP地址.md)），然后用手机或电脑连接同一个 Wi-Fi（确保同一局域网）
3. 通过浏览器访问：http://<机器人IP>/network
4. 点 Scan 按钮手动扫描
5. 等下拉框出现结果
6. 选网络，密码框规则：

   - 开放网络：无需密码
   - 已保存网络：留空 = 沿用存储的密码；输入新密码 = 覆盖旧密码（这是改密码变了的路由器的唯一途径）
   - 全新网络：必须输入
7. 点 Switch & Reboot
