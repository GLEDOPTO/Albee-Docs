# Device Freeze or Reboot Feedback Guide

If your device freezes or reboots unexpectedly, please send an email to [Sales@gledopto.com](mailto:Sales@gledopto.com) with the following information:

1. **What was happening at the time**: What state was the device in? What were you doing?
2. **Boot reason**: Talk to Albee to get its IP address, then visit `http://<device-ip>/info` in a browser, check the boot reason, and provide it (see the example below). Note: your phone or computer must be on the same local network as Albee. **When providing the boot reason screenshot, do not restart or upgrade the device — you need to visit this page as soon as possible after the freeze/reboot to capture the information.**

![](../../assets/img/problem-feedback/1.png )

3. **Run logs (if available)**: If you have a serial terminal tool on your computer, connect Albee with a Type-C cable and check the device run logs. If you find any error messages, please include them as well to help troubleshoot the problem.
